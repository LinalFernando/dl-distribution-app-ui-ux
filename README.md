# DL Distribution App – UI/UX Design

A modern **mobile Distribution and Order Management application UI/UX design** created using **Figma**.

The project focuses on designing simple and user-friendly interfaces for managing customers, products, orders, sales, returns, and related distribution activities.

## 🎨 Project Overview

The **DL Distribution App** is a mobile application UI/UX concept designed to support distribution and sales-related business workflows.

The design focuses on:

* Simple and intuitive navigation
* Clean and modern mobile interfaces
* Easy customer and product management
* Efficient order and sales workflows
* Clear return management processes
* Consistent visual design
* Improved user experience
